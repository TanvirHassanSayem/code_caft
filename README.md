## 🚀 Overview

**Code Caft** is a cutting-edge starter kit built with Next.js 14, Tailwind CSS, Clerk authentication, and Convex state management. Optimized for developer productivity, performance, and scalability. Perfect for modern web apps—from prototypes to production.

## ✨ Key Features

- **⚡ Next.js 14**: App Router, ISR/SSR, image optimizations
- **🎨 Tailwind CSS**: Utility-first styling with JIT mode
- **🔒 Clerk Auth**: Seamless user sign-up/sign-in flows
- **🗃️ Convex**: Backend-less state & database
- **📱 Mobile-First**: Fully responsive & accessible
- **🌐 Geolocation**: Built-in internationalization support
- **🧪 Testing**: Planned Jest & React Testing Library integration

## 📥 Getting Started

1. **Clone Repository**
   ```bash
   git clone https://github.com/TanvirHassanSayem/code_caft.git
   cd code_caft
   ```
2. **Install Dependencies**
   ```bash
   npm install
   # or yarn install
   # or pnpm install
   ```
3. **Configure Environment**
   - Duplicate `.env.example` to `.env.local`
   - Add your **Clerk** and **Convex** keys

4. **Run Development Server**
   ```bash
   npm run dev
   ```
5. **Open App**
   Navigate to [http://localhost:3000](http://localhost:3000)

---

## 🛠️ Usage Guide

- **Routes & Layouts**: Edit or add pages in `app/`.
- **Styling**: Customize `tailwind.config.js` for themes and plugins.
- **Authentication**: Manage users via the [Clerk Dashboard](https://dashboard.clerk.dev).
- **State**: Use Convex for real-time data sync without a custom backend.
